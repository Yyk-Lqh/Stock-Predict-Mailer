# 会话式分析工作台

2026-11-10。基于已确认的三栏工作台方案实现，复用当前后端接口，不改变本机同源、CSRF 与私有访问密钥的权限边界。

## 使用路径

- 左侧「新建分析」创建私有会话。首次使用会创建访问密钥，请在「记忆与访问」复制并妥善保管；关掉标签页后需输入原密钥恢复。服务端仍须沿用原主密钥。
- 默认进入分析工作台。预测、客观事实、知识检索问题与运行选项按需展开，本轮问题放在输入框中。示例按钮会准备 Mock 模型及合成数据，仍需点击提交。
- 一轮分析对应一个任务；一段会话可以包含多轮分析。追问沿用最近一轮预测并重新验证有效期，更新预测需展开预测表单。过期草稿不会自动顺延日期。
- 会话草稿按会话 ID 分开保存于本机浏览器，包含本轮问题和约束。请勿在草稿里填写凭据。切换会话与恢复位置后，邮件通知默认关闭，须每轮明确选择。
- 中间显示真实任务状态、运行轨迹与图表，阶段和事件在执行详情中查看。右侧报告可以关闭或展开，并可下载 HTML 与分析 JSON。任务、分析降级与投递状态分别显示。
- 左侧任务记录兼容旧的独立任务。会话工具支持导出和删除；删除会话保留长期记忆及历史报告，运行中的会话由服务端拒绝删除。

## 知识库

「资料与版本」支持上传、版本状态、原文与清洗片段对照、原件下载、失败重试、重新提取及删除。上传返回只代表已排队。清洗 worker 仍需使用同一主密钥和 workspace 独立启动；页面没有 worker 心跳接口，不宣称 worker 在线。

待审阅版本提供候选引文、源片段、校验结果、声明和有效期。只有校验通过的候选可勾选；批准携带本批 digest，过期批次由服务端拒绝。批准后仍需 worker 完成发布。拒绝保留旧活动版本。

「检索证据」支持截止日期、股票代码和主体过滤，并可查看引用源版本与行、页等定位。「处理与索引设置」提供独立的清洗模型、Embedding 配置及索引重建。测试和远程索引重建可能产生模型调用，页面在操作前明确提示。

分析输入中的知识检索使用 `knowledge_query` 和 `knowledge_to_model`；后端按预测生成日期取证。当前接口不能按用户勾选的单个文件筛选，因此页面没有文件选择器。即使填写检索问题，也只有明确允许后才会将证据传入分析模型。

## 实现结构

- `control/web/app.js`：既有配置、表单、事件轮询与报告渲染，并调用工作台生命周期。
- `control/web/modules/memory.js`：长期记忆与访问密钥基础操作。
- `control/web/modules/workspace.js`：布局、会话分页、历史轮次、草稿切换、报告面板、导出及位置恢复。
- `control/web/modules/knowledge.js`：资料、审阅、检索、引用定位与模型配置。
- `control/web/memory.js`：以上模块的生成产物，保持现有服务端四个静态资源路径兼容，无需重启已有服务即可更新界面。

修改模块后运行 `uv run python scripts/build_console.py`。CI 使用 `--check` 确认生成产物没有遗漏，并检查两个浏览器脚本的语法。

## 验证与复验

后端验收：`uv run python -m unittest discover -s tests -p test_control.py -q`。

浏览器验收必须使用独立测试服务，避免产生测试会话到实际工作区：

```powershell
uv run python tests/browser_console_fixture.py --port 8768
# 在另一终端使用已安装的 gstack browse，可执行文件路径依本机安装位置而定。
browse goto http://127.0.0.1:8768
browse eval tests/browser_console_flow.js
browse wait 'body[data-test-result]'
browse attrs body
```

`data-test-result` 包含断言结果，覆盖首次提问保留、两轮真实 Mock 任务、通知默认关闭、跨会话草稿隔离与恢复。此脚本仅可在测试服务执行，会创建测试会话。

本次另以合成资料验证了 UI 上传、模拟语义清洗、原文对照、候选批准、worker 发布、按词检索与来源定位。390px 窄屏验证无横向溢出。没有调用真实模型、发送真实邮件或验证 OCR。

## 当前范围

未添加会话重命名、置顶、全局搜索、邮件批量发送/重试或 worker 进程管理；它们需要额外后端契约。索引重建沿用现有同步接口，没有虚构进度百分比。既有配置页保留，协作配置按组折叠并提供知识处理、记忆入口。

## 白天与晚上主题
工作区右上角可切换白天和晚上。白天使用白色工作区与浅灰侧栏，晚上保留石墨主题；报告面板、知识库、表单与状态提示随主题切换。选择保存在当前浏览器，刷新后恢复，首次默认晚上。浏览器禁用本地存储时仍可在当前页面切换。

## 小马办公室
分析页已以固定工位与彩色围巾角色展示真实协作阶段，执行进度和阶段产出集中到右侧面板。通行、事件恢复与验证方法见 [小马办公室](pony-office.md)。

## 顶部导航
主导航已从左侧移到顶部，分析会话收纳为顶部下拉菜单。正文释放左侧空间，报告面板避开两层顶部工具栏；手机端的功能导航可横向滚动。办公室协作门移到场景标题区域。会话菜单支持点击外部或 Escape 关闭。

## 底部对话栏与分析资料抽屉
分析页仅保留办公室、会话历史和底部固定对话栏。橙色分析助理是界面角色，点击后打开右侧分析资料；不新增模型调用。抽屉分为分析资料、工作进度、报告与证据，复用原表单与报告控件，切页不重建输入。发送组合结构化资料及本轮 message；缺资料时定位字段并保留问题。Enter 发送、Shift+Enter 换行，中文组合输入不发送；成功创建任务后才清空问题。
新模块 web/modules/analysis-input.js 管理抽屉、校验和对话栏。使用 scripts/build_console.py 构建。独立测试服务可用 gstack browse eval tests/browser_analysis_input.js 检查资料校验、助理入口、页签保留与输入法提交，读取 body[data-analysis-check] 查看断言结果。
