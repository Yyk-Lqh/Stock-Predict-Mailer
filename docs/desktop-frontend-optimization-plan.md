# 桌面前端优化计划

日期：2026-11-17。用户授权按优化清单规划并开始实施，随后明确手机端无需修改。

**持续约束（用户再次明确）：只优化桌面端。手机端不纳入实现、适配、检查或回归测试；后续阶段同样遵守，不再为手机端安排工作。下文先前已经完成的验证记录仅作为历史保留。**

## 范围与方向

采用渐进改造：保留顶部导航、小马证券大厅、原生 HTML/JS 及当前后端契约，先让用户完成分析主流程，再逐项完善业务页面。

比较过三种路径：只调整视觉无法解决资料入口隐蔽的问题；一次重建所有页面会扩大联调范围；因此选择分阶段改造现有工作台。桌面新增内容只在 761px 及以上启用，手机端使用原有页面、交互和样式。宽度跨越断点时恢复原有状态。

视觉沿用现有石墨/浅色主题、系统中文字体、等宽数据字和黄铜色操作强调；不增加外部字体或依赖。小马大厅保留为项目特色，增加可记住选择的专注分析视图。状态来自当前表单、模型配置和真实任务，不根据动画猜测执行情况。

## 阶段一：分析主流程（已实施）

1. 工作台顶部增加流程操作区：选择模型、准备分析资料、查看进度/报告。首次使用可直接填写资料或准备离线示例。
2. 显示实际默认模型、标的/周期、校验待办和当前任务状态；明确缺少事实不阻止分析，报告需说明限制。
3. 默认进入专注分析，可切换小马大厅并保存浏览器偏好。专注视图突出资料摘要、会话和后续问题，不复制或重建表单。
4. 从桌面资料入口打开时展开预测必填部分；按页签显示正确的面板标题，关闭后将焦点返回可见入口。历史轮次通过对话栏的“会话记录”打开，避免挤压输入区与大厅；原有记录节点和草稿保持。
5. 桌面增加持续的提交准备/任务反馈；保持原有输入校验、输入法、草稿隔离、每轮邮件授权、三种业务状态及证据语义。
6. 运行新浏览器验收、既有分析输入/多轮会话回归、构建同步及静态检查，检查深浅主题和常见桌面尺寸。

验收：无模型时能直接定位设置；无资料时一步到表单；示例必须明确说明切换 Mock 且不自动提交；错误不清空问题；提交后能跟进真实进度并打开报告；追问沿用原预测；切换会话不串草稿；刷新保留视图偏好；手机宽度不出现新增界面或改变原操作。

## 阶段二：报告、历史和知识库

### 阶段二 A：报告与历史往返（已实施）

本轮先打通一份报告的阅读闭环，后续二 B 再完善知识库处理/审阅与预测归档。比较了仅放大原抽屉、整体重排原报告和独立桌面增强层：选择增强层，保留原章节与下载行为，让新增摘要和导航在手机端自动退出。

1. 在已有报告标题下展示“阅读重点”，摘取原报告的前两条 Agent 推断、风险和限制，明确这不是新生成的结论。降级与合成数据、任务/分析/邮件状态保持可见，缺少数据时省略该段，不编造置信度或结论。
2. 支持“完整报告 / 只看重点”。原章节与目录保留，点击章节或证据时先展开完整内容。利用现有展开按钮进入桌面专注阅读，释放对话栏空间，退出、切换页签或关闭时正确恢复。
3. 支持推断到事实/预测、事实到引用推断以及返回引用处。引用与高亮只根据当前报告中的实际 ID 建立，切换任务后清除旧引用，不将缺失引用当成已核对证据。
4. 从任务记录进入报告时显示返回入口；保留现有筛选与搜索内容，返回原记录和滚动位置。说明筛选范围仅为已载入记录，不伪装成全局搜索。
5. 可复制已有报告重点，剪贴板不可用时提供可手动复制的纯文本。沿用已有 HTML/JSON 下载与知识证据接口，所有外部内容按文本渲染。

验收：真实 Mock 任务报告可读，核心段落与原文一致；降级、合成、未知邮件状态明确；引用能往返且键盘可用；只看重点不妨碍打开章节；专注阅读退出后对话栏可用；任务切换不串证据；历史返回保留筛选及位置；手机继续使用原始报告与操作。

### 阶段二 B：知识库与预测跟踪（已实施）

选择在原有页面上增加桌面工作清单，而不再创建一个独立总览页。继续使用现有主题、原生表单与四个静态资源路径。服务端已有的资料 status 查询用于待办筛选；名称筛选明确限于已载入版本。

1. 知识库展示当前私有空间的真实状态计数，快捷筛选待审阅、排队、处理中、失败和已发布。直接打开原上传表单；清洗进程是否在线仍依据既有队列心跳，不编造处理百分比。
2. 详情展示服务记录的处理阶段与活动版本说明，可切换实际版本并返回列表。候选审阅增加选择计数及摘录/来源并排核对，保留原校验、digest、逐项勾选和批准/拒绝确认。桌面详情和检索添加最新请求保护，身份变化清空新增内容。
3. 预测归档提供状态快捷入口和已载入范围说明，定位当前列表里的待观测预测。详情明确待到期、待观测、已有回执的区别；提供带占位符的 JSON/CSV 格式参考，仅供阅读，不填写实际数值或来源。
4. 成功预览展示标的、指标、单位、合成标记与目标观测时点的声明一致性。持续强调未保存及来源未独立认证，不新增正式回执写入。
5. 任务记录增加按服务状态记录时间显示的日期分隔，保持既有排序、筛选与返回定位。新增样式仅使用桌面断点；本轮不安排任何手机端实现、适配或检查。

验收：合成文件上传/待审阅/批准后发布链路正常；版本切换不被迟到响应覆盖；未通过校验的候选仍不可批准；筛选与计数范围明确；占位符不会写入观测；预览和已保存回执分开；编辑、换任务或换身份后没有旧结果残留；既有桌面流程可用。

阶段二 B 覆盖以下既定条目：

- 任务与会话列表摘要、日期分组、筛选范围说明和返回位置。
- 知识资料处理阶段、待审阅入口、版本关系、原文/提取结果对照与检索反馈。
- 预测归档与观测预览的状态入口、格式示例、逐项匹配以及未保存标识。

本轮完成任务日期分隔及知识库/预测主流程；会话列表进一步摘要与分组留作后续小项，全局历史搜索、会话重命名和置顶仍需独立接口设计。

全局服务端历史搜索、会话重命名/置顶及正式评估回执保存需先设计后端接口，不通过假按钮冒充已支持。
