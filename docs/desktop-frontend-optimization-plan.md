# 桌面前端优化计划

日期：2026-11-17。用户授权按优化清单规划并开始实施，随后明确手机端无需修改。

**持续约束（用户再次明确）：只优化桌面端。手机端不纳入实现、适配、检查或回归测试；后续阶段同样遵守，不再为手机端安排工作。下文先前已经完成的验证记录仅作为历史保留。**

## 范围与方向

采用渐进改造：保留顶部导航、小马证券大厅、原生 HTML/JS 及当前后端契约，先让用户完成分析主流程，再逐项完善业务页面。

比较过三种路径：只调整视觉无法解决资料入口隐蔽的问题；一次重建所有页面会扩大联调范围；因此选择分阶段改造现有工作台。桌面新增内容只在 761px 及以上启用，手机端使用原有页面、交互和样式。宽度跨越断点时恢复原有状态。

视觉沿用现有石墨/浅色主题、系统中文字体、等宽数据字和黄铜色操作强调；不增加外部字体或依赖。小马大厅保留为项目特色，增加可记住选择的专注分析视图。状态来自当前表单、模型配置和真实任务，不根据动画猜测执行情况。

## 阶段一：分析主流程（已实施）

1. 工作台顶部增加流程操作区：选择模型、准备分析资料、查看进度/报告。首次使用可直接填写资料或准备离线示例。
2. 显示实际默认模型、标的/周期、校验待办和当前任务状态；明确缺少事实不阻止分析，报告需说明限制。
3. 默认进入专注分析，可切换小马大厅并保存浏览器偏好。专注视图突出资料摘要、会话和后续问题，不复制或重建表单。
4. 从桌面资料入口打开时展开预测必填部分；按页签显示正确的面板标题，关闭后将焦点返回可见入口。历史轮次通过对话栏的“会话记录”打开，避免挤压输入区与大厅；原有记录节点和草稿保持。
5. 桌面增加持续的提交准备/任务反馈；保持原有输入校验、输入法、草稿隔离、每轮邮件授权、三种业务状态及证据语义。
6. 运行新浏览器验收、既有分析输入/多轮会话回归、构建同步及静态检查，检查深浅主题和常见桌面尺寸。

验收：无模型时能直接定位设置；无资料时一步到表单；示例必须明确说明切换 Mock 且不自动提交；错误不清空问题；提交后能跟进真实进度并打开报告；追问沿用原预测；切换会话不串草稿；刷新保留视图偏好；手机宽度不出现新增界面或改变原操作。

## 阶段二：报告、历史和知识库

### 阶段二 A：报告与历史往返（已实施）

本轮先打通一份报告的阅读闭环，后续二 B 再完善知识库处理/审阅与预测归档。比较了仅放大原抽屉、整体重排原报告和独立桌面增强层：选择增强层，保留原章节与下载行为，让新增摘要和导航在手机端自动退出。

1. 在已有报告标题下展示“阅读重点”，摘取原报告的前两条 Agent 推断、风险和限制，明确这不是新生成的结论。降级与合成数据、任务/分析/邮件状态保持可见，缺少数据时省略该段，不编造置信度或结论。
2. 支持“完整报告 / 只看重点”。原章节与目录保留，点击章节或证据时先展开完整内容。利用现有展开按钮进入桌面专注阅读，释放对话栏空间，退出、切换页签或关闭时正确恢复。
3. 支持推断到事实/预测、事实到引用推断以及返回引用处。引用与高亮只根据当前报告中的实际 ID 建立，切换任务后清除旧引用，不将缺失引用当成已核对证据。
4. 从任务记录进入报告时显示返回入口；保留现有筛选与搜索内容，返回原记录和滚动位置。说明筛选范围仅为已载入记录，不伪装成全局搜索。
5. 可复制已有报告重点，剪贴板不可用时提供可手动复制的纯文本。沿用已有 HTML/JSON 下载与知识证据接口，所有外部内容按文本渲染。

验收：真实 Mock 任务报告可读，核心段落与原文一致；降级、合成、未知邮件状态明确；引用能往返且键盘可用；只看重点不妨碍打开章节；专注阅读退出后对话栏可用；任务切换不串证据；历史返回保留筛选及位置；手机继续使用原始报告与操作。

### 阶段二 B：知识库与预测跟踪（已实施）

选择在原有页面上增加桌面工作清单，而不再创建一个独立总览页。继续使用现有主题、原生表单与四个静态资源路径。服务端已有的资料 status 查询用于待办筛选；名称筛选明确限于已载入版本。

1. 知识库展示当前私有空间的真实状态计数，快捷筛选待审阅、排队、处理中、失败和已发布。直接打开原上传表单；清洗进程是否在线仍依据既有队列心跳，不编造处理百分比。
2. 详情展示服务记录的处理阶段与活动版本说明，可切换实际版本并返回列表。候选审阅增加选择计数及摘录/来源并排核对，保留原校验、digest、逐项勾选和批准/拒绝确认。桌面详情和检索添加最新请求保护，身份变化清空新增内容。
3. 预测归档提供状态快捷入口和已载入范围说明，定位当前列表里的待观测预测。详情明确待到期、待观测、已有回执的区别；提供带占位符的 JSON/CSV 格式参考，仅供阅读，不填写实际数值或来源。
4. 成功预览展示标的、指标、单位、合成标记与目标观测时点的声明一致性。持续强调未保存及来源未独立认证，不新增正式回执写入。
5. 任务记录增加按服务状态记录时间显示的日期分隔，保持既有排序、筛选与返回定位。新增样式仅使用桌面断点；本轮不安排任何手机端实现、适配或检查。

验收：合成文件上传/待审阅/批准后发布链路正常；版本切换不被迟到响应覆盖；未通过校验的候选仍不可批准；筛选与计数范围明确；占位符不会写入观测；预览和已保存回执分开；编辑、换任务或换身份后没有旧结果残留；既有桌面流程可用。

阶段二 B 覆盖以下既定条目：

- 任务与会话列表摘要、日期分组、筛选范围说明和返回位置。
- 知识资料处理阶段、待审阅入口、版本关系、原文/提取结果对照与检索反馈。
- 预测归档与观测预览的状态入口、格式示例、逐项匹配以及未保存标识。

本轮完成任务日期分隔及知识库/预测主流程；会话列表进一步摘要与分组留作后续小项，全局历史搜索、会话重命名和置顶仍需独立接口设计。

全局服务端历史搜索、会话重命名/置顶及正式评估回执保存需先设计后端接口，不通过假按钮冒充已支持。

## 阶段三：配置和独立数据接入中心（已实施）

### 本轮设计与实施范围

继续渐进改造原表单，保留字段节点、完整设置保存及既有接口，增加桌面分组和操作反馈。只使用桌面样式与合成验收环境。

1. 设置顶部区分已保存配置与表单预览。模型表单分为基础信息、远程连接/手动报价和高级参数；Mock 使用离线配置。保存后继续编辑同一配置，分别显示本页面测试结果与默认选择。只有用户点测试才发起推理测试，真实服务明确提示可能计费；密钥不进入浏览器存储或摘要。
2. MCP 发现结果提供显式工具白名单与权限类型编辑，修改只写入待保存表单，不因发现而授权。保留资源精确 URI、原 JSON 高级字段及未知工具权限，不自动启动外部进程或测试真实服务。
3. 协作设置提供分组定位、未保存提示、角色模型/温度继承预览以及邮件通道字段分层。仍提交完整 settings 克隆，保留页面未展示的 SMTP 环境变量等字段；预算预览只描述表单上限，实际生效以任务回执为准。
4. 数据接入中心提供按文件数的批量结果、显式失败重传、已载入文件名/状态筛选、待确认事项与问题定位、字段映射编辑辅助。上传仍顺序执行，不伪造网络字节进度或后台清洗百分比。发布继续依赖原服务门禁，已发布标记只表示本次页面收到的回执。
5. 独立接入中心沿用石墨/黄铜主题并增加桌面浅色选项。选择和重清洗采用最新请求保护；无效映射不丢输入，较慢的旧处理结果不得覆盖用户后来选择的文件。

验收：保存/测试/默认选择分开；Mock 无真实请求；JSON 错误能定位且保留输入；刷新配置不丢协作草稿；未知设置字段保留；发现不授予权限；密钥不回显/存储；合成文件上传、失败重传、信息补充、重清洗和显式发布可用；迟到响应不覆盖新选择；仅验证桌面尺寸和主题。

## 阶段四：基础组件与性能治理（A / B / C 已实施）

1. 先测量桌面初次加载、生成脚本解析、场景绘制、隐藏页面与轮询成本，记录基线，再按结果选择优化项。
2. 检查已加载长列表的过滤、重复渲染和定位开销；明确服务端分页与本页筛选范围，保留用户选择和滚动位置。
3. 在实际改造页面逐步统一表单、空态、加载、错误重试与焦点反馈；按当前流程验收，避免只复制外观。
4. 清理重复样式时限定影响面；资源拆分须与服务端四个静态路径白名单兼容。继续只开展桌面工作。

### 阶段四 A：设计与验收（已实施）

2026-11-17，按用户指示继续规划并实施。先在临时 Mock 工作区测量，再选择改造项。对比复用既有节点、全面虚拟列表和拆分脚本：本轮采用可见性控制与节点复用，直接处理已测开销；虚拟列表会增加键盘定位与报告返回的复杂度，脚本拆分还涉及静态资源契约，暂不扩大范围。

- 初始基线（本机 headless Chromium，1440×1000）：导航完成约 180ms，FCP 84ms；生成脚本约 1.82MB。隐藏大厅 1200ms 内仍产生 7823 次场景 DOM 变更，可见大厅 7779 次；设置页为 0。1500 条任务未变化刷新约 149ms、复用 0 行；4000 条文件的 15 次名称筛选中位约 698ms。均为合成列表和本机样本，不作为所有机器的耗时承诺。
- 桌面大厅只在分析页、大厅模式且未被专注报告遮蔽时持续绘制。隐藏时保留后端任务状态同步及实际进度；恢复时重绘最新状态，不补跑隐藏期间的动画。页面生命周期只维护一个动画循环。
- 桌面任务记录按任务 ID 复用按钮；可见内容改变时更新原按钮内容，数据和点击动作使用最新任务。仅协调实际增删/排序，保留仍可见记录的键盘焦点。日期分组和已加载筛选范围继续明确。
- 刷新读取最新页并合并已加载历史，分页结果按 ID 去重；最新页与已加载范围不相交时保留继续读取间隙的游标。已加载但不在最新页的运行任务单独校准状态。刷新失败保留当前记录、筛选和分页，持续显示失败及重试入口；离开任务页后停止列表刷新。访问密钥切换/撤销时清空记录缓存，旧身份迟到请求不得回填，也不得解除新请求的忙碌状态。
- 独立接入中心缓存文件索引、规范化名称和状态计数，使名称筛选按行线性遍历；刷新复用文件按钮，选择文件不再无条件重建列表。

验收：同一测量脚本比较前后开销；隐藏场景无持续 DOM 变更、显示恢复且真实 Mock 任务仍完成；不变列表不重建任务按钮；新/旧分页不重复不丢历史，旧运行任务得到校准；刷新错误持续可见并可重试，旧数据与当前选择保留；深浅主题和桌面尺寸验证通过。仅改桌面路径，不新增依赖、静态端点、真实模型或邮件调用。

### 阶段四 B：桌面轮询、启动预算与会话反馈（已实施）

1. 测量桌面任务轮询在切页、恢复标签页及请求较慢时的数量与重叠，优先处理确实存在的重复读取，同时保持任务取消、断线和终态回执正确。
2. 记录生成脚本的大小预算和解析开销，评估小马静态资源的加载方式；只有兼容既有资源路径且测量显示有收益时才拆分或延后初始化。
3. 核对会话列表摘要、空态和重试入口的一致性，复用真实会话/任务信息，并保留筛选范围、焦点及当前草稿。

本轮按用户指示规划并实施，继续只针对桌面。基线测量使用固定的五次并发读取：任务和事件各请求 5 次、最大并发 5；1000ms 后累计各 10 次，说明保留了多条链。会话最新页同样请求 5 次、最大并发 5。初次本机导航约159ms/FCP88ms；生成脚本1,829,647字节，其中静态小马轮廓1,521,058字节。单次启动样本不证明拆分或延后初始化的收益。

本轮采用一个桌面读取协调器，保留原轮询作为原有路径。相较简单延迟触发和新增推送接口，协调器能合并在途请求、只维护一个后续计时器，并沿用现有任务/事件接口。具体范围：

- 同任务读取共享在途请求，正常间隔700ms、读取失败后2500ms重试；单次读取超过8秒中止并提示。离开分析页、隐藏标签页或页面暂停时停止计时和在途读取，服务端任务继续；返回后立即按原事件游标读取。终态在事件批次读完后停止；再打开历史任务可重新读取。
- 每次读取绑定任务、访问密钥和代次。切任务、换空间、取消及旧响应的完成处理不能覆盖新任务。取消响应按当时任务应用，再校准后续事件；不把用户中止读取显示成连接失败。
- 进度页持续显示读取失败和手动重试入口；不宣称请求失败等于任务失败。真实任务、报告、取消及断线恢复继续使用原接口。
- 桌面会话列表合并并发请求，刷新保留已加载历史、游标与仍可见的焦点；提供仅针对已加载名称的筛选、实际更新时间、空态和持续失败/重试。点击仍走原会话选择和草稿保存逻辑，不编造轮次或全局搜索结果。换访问密钥清空缓存并取消旧读取。
- 增加构建大小报告与可复验预算：生成脚本≤1,900,000字节、主脚本≤100,000字节、样式≤110,000字节。它们是基于当前体量的项目增长约束；静态轮廓保持原样，不声称启动提速。

验收：同一并发脚本中任务/事件及会话请求各合并为1次；终态、事件分页、失败重试、取消/切换/隐藏恢复和身份隔离均可复验；真实 Mock 分析与已有草稿/报告流程通过；会话筛选、分页、焦点与错误状态真实可用；构建/预算与桌面深浅主题通过。保留前序未提交改动，不开展任何手机端工作。

### 阶段四 C：桌面交互收尾（已实施）

1. 按首次使用、资料、分析、报告、历史与恢复复核桌面关键路径，处理实际发现的按钮状态、错误恢复和键盘焦点问题。
2. 核对桌面较短窗口、长名称和深浅主题下的提示密度、阅读与操作遮挡，收敛重复说明，保留真实状态与来源边界。
3. 固化桌面验收入口、资源预算与变更清单，再审阅整体改动。保持现有业务/API范围，不增加手机端工作或未经请求的发布。

本轮按用户指示规划并实施。gstack 在1280×600复现：弹出菜单和会话菜单的Escape会连带关闭资料面板；会话历史请求较慢时，表单已锁定但移出的对话框仍能输入，恢复既有草稿后覆盖这段文字；旧引导与会话操作区会重新出现并覆盖专注摘要。摘要的超出内容实际可滚动到达，不将正常滚动误判为不可访问。

采用小范围桌面交互层和现有处理函数钩子，不重写菜单/对话框。完整替换组件会扩大表单与权限回归面；只加样式无法修复键盘和异步覆盖。本轮设计：
