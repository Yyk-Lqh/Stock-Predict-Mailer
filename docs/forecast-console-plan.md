# 阶段 6C：控制台预测评价入口

2026-11-16，承接用户“规划好下一步，然后开始实施”的授权和 6B 后续步骤。

采用现有分析资料面板中的可选评价表单，以及记录页内的预测归档区。保持已有色彩、字体、卡片和移动端布局，不增加独立导航层级。相较于仅编辑原始 JSON，结构化表单能明确目标时点、时区、指标、单位、平盘阈值、基准及日历；保留完整定义 JSON 的导入入口以便复用上游文件。不推断价格、交易日或观测。

归档默认关闭；启用时把定义写入本轮请求。成功提交后清除本轮开关/定义，切换预测或新建/切换会话时清除旧定义；尚未提交的同一草稿允许恢复。评价字段修改不得改写预测 ID、生成时间、数值或图表。完整定义可从原始 JSON 回填，发送前由后端执行契约校验。

归档 API 只能查看有权访问的任务关联记录，沿用本机会话和私有记忆密钥规则。禁止提供可按任意 forecast_id 查询全工作区的接口，CLI 独立注册且未关联任务的档案不出现在页面。列表按任务游标分页，返回本页扫描任务数，不把分页计数冒充全档案总数；支持状态筛选、刷新、更多与空/错误提示。重复预测在页面合并展示。任务失败或取消后仍可通过已持久化 forecast 事件查看已注册记录。

详情显示目标/定义、预测及评估回执；明确合成标记、指标单位及“到期不等于已评估”。提供只读 GET 接口，不在页面接入自动观测、评分、改写或发送邮件。限制任务扫描、读取字节及响应大小，损坏记录明确报错。报告面板增加归档入口。

实施：先完成权限隔离和有界查询；再接入表单及记录/详情；补充 HTTP 隔离、分页、故障与前端流程测试；通过 gstack 浏览器验收桌面/移动布局、显式启用、提交后清理、状态与详情及错误恢复。所有测试使用临时合成工作区。
