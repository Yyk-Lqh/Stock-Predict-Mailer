# 阶段 6D：显式观测导入与评估预览

承接 6C 后续步骤及用户“规划好下一步，然后开始实施”的授权，2026-11-16。

选择完整 JSON 或固定字段的单行 CSV 导入，保留原始文本供核对。相比自动识别任意行情 CSV 或直接查询外部服务，此方案明确指标、单位、来源、合成标记与精确观测时点，不猜测复权方式或交易日。服务端拒绝多行择样、重复/额外字段和非有限数字；单文件/文本上限 256 KiB。

增加 POST /api/tasks/{id}/forecast/preview，沿用本机会话、Origin/Host、CSRF 与私有任务 owner 权限；不接受任意 forecast_id。请求为 observation 对象，或 format=json/csv 与 content 原始文本，可显式提供 as_of。只读取该任务关联档案，以同一份已校验记录计算；复用纯 observation 契约和十进制 score，完全不调用归档写入或正式 evaluate 路径。

先完整解析并校验观测，即使未到期也拒绝错标的、指标、单位、合成标记和时点。截止不能晚于现在或早于注册。未到期返回 not_due；观测可用时间晚于截止返回 awaiting_observation；符合条件返回可核对的 metrics。响应始终 persisted=false，不产生 evaluation 回执字段，显示观测内容摘要、导入文本摘要、预测内容摘要及限制说明。摘要仅用于一致性核对，不表示来源认证。

详情页增加“导入观测并预览”折叠区，支持文件选择和粘贴/编辑原文，截止时间可选。提交前显式点击预览，错误在本区提示，来源按文本显示；不自动生成实际观测或使用事前基准替代。编辑输入、切换任务/筛选/身份、关闭详情后清除旧预览；丢弃慢响应，防止过期评分重新出现。不保存浏览器观测草稿，不在页面提供正式保存/发送按钮。

沿用现有石墨/黄铜色、字段布局及移动端断行，预览与正式回执使用明确不同文案。按当前流程使用 gstack /browse 验收。验证 JSON/CSV 解析边界、时点门禁、原预测已过有效期仍可评估、权限/CSRF、读取预算、不写入及前端竞态/错误恢复；完整回归、基础 wheel、源码目录外 HTTP 冒烟均用临时合成数据。

真实采集、外部观测适配器、批量统计、正式保存回执与托管浏览器 CI 不在本轮范围内，后续独立实施。
