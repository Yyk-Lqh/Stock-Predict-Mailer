# 小马办公室：布局、围巾、通行与时钟验收

2026-11-13。保留工作区现有导航、主题、对话栏和模型工具栏改动，在原有缩桌、围巾及寻路的部分修复上继续完成。

## 调整内容

- 六工位列中心改为220／525／830，排中心160／430。列间距由285增至305，排间距由250增至270；桌面宽184.8缩至171.6，桌面深度缩至原来的86%。相邻桌面留白约133.4局部单位。后排标签与前排椅轮之间保留21单位，显示器、键鼠保持原尺寸，避免缩小可读内容和输入接触面。
- `PonyFloor.furniture` 同时定义桌子缩放、桌椅地面范围、座位与进出点。入座通道允许进入自身桌椅占位，普通通行仍检查全部设施。场景纵向范围扩大至700，后排通道可走至670，顶部保留130单位角色高度；橙色助理移至后方独立待命位置。角色安全半径提高至40，动态中心安全距离83。
- 保留已有的角色固定围巾色与中性细织纹，移除不再使用的噪声材质滤镜。主体、颈圈与垂端沿用同一角色颜色；流苏镂空仍显示其后的真实背景，不把孔隙计作布料变色。
- 寻路改用二叉堆、八邻域和障碍缓存；路径简化检查完整线段与矩形、圆形占位的交点。角色可以离开已经接触安全边缘的位置。相向通行按稳定角色优先级选择让行位，重规划有间隔，每帧限制规划次数；移除每次横向转向都停顿的处理。SVG轮廓缓存与属性值去重减少无效绘制，缺席角色跳过关节与轮廓绘制。
- 真实时钟读取浏览器本机 `Date`，显示当地 `HH:mm:ss` 与日期，和随机屏保淡入淡出。隐藏页面恢复、切换回分析、窗口获得焦点及页面恢复时强制刷新；沿用单个动画循环，没有新增轮询定时器。任务状态始终覆盖屏保。

## 发现并解决的回归

开始时 `tests/test_pony_floor.cjs` 的「减少动态效果仍能正确到达」失败。贴边路径的离散采样会漏掉碰撞，角色停住后又无法在加了安全余量的网格中找到合法起点。整段碰撞检查及向外退让规则修复该问题。

两小时仿真进一步发现把手占位冲突：进门角色仍站在室内门侧时，出门角色可能沿靠门动画进入相同位置。现在接近把手前检查目标占位，动画每一步检查其他角色，并保存失败路径的目标以便重新规划。扩大动态间距后，另修正非工位助理的返回点，避免阻挡后排工位的进出点。

## 验证结果

- 现有角色与导航 Node 回归全部通过；新增 `tests/test_pony_office_refinement.cjs` 覆盖共享家具占位、两条通道相向通行、退让、门口占位、日期时间和任务优先级。相向测试最小距离不少于83.0，不发生地面占位重叠。
- 两小时生命周期仿真通过：四只访客、10,574次门槛采样，无碰撞或动作阶段持续超过60秒，包含访问、离开、闲逛、任务召回和门口排队。
- 六工位真实SVG接触检查通过：1320次键盘、268次鼠标接触，DOM节点稳定。桌面缩放没有缩放键鼠接触点。
- 围巾栅格检查覆盖七个角色、322组动作与镜像、851,809个布料内部像素；零失败，最大色相差约0.52度。步态18相位以及坐姿、入座、起身、门口动作均有覆盖。
- 不录制时，实际办公室240帧短测约60.00fps，帧间隔中位数16.7ms、p95约16.7ms；采样包含388次行走角色观测。该结果是本机短测，不是跨设备性能保证。
- 同一条畅通走道120次规划微基准，中位耗时由约2.98ms降至0.015ms；这是直线路径特定场景，不代表所有寻路耗时。最终连续通行录像覆盖双向通过及4次转向，最小动态距离83.185；7次规划中位0.6ms、最大10ms，恢复后的时钟与浏览器当前时间一致，任务优先级检查通过。
- 真实时钟恢复检查对比显示值与同一浏览器当前时间，任务到来后切换为任务画面。日期时间单测使用固定本地日期，验证不同动画累计时间不会影响真实时间。

网页操作均通过 gstack `/browse`。`tests/browser_pony_traffic.js` 只允许在8768隔离服务中运行，明确注入演示路线，使用真实 `Floor.tick` 与 `PonyRig`，未调用真实模型或SMTP。
