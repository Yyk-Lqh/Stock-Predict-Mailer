## 画面与业务

六个固定工位：红色主 Agent、绿色预测分析、紫色风险分析、黄色建议生成、青色图表功能、蓝色邮件功能。主 Agent 与邮件角色常驻，其余按真实阶段调用进场。图表和邮件标为功能模块，没有增加不存在的模型服务。

办公室使用分层 SVG 家具及可独立旋转的头、手臂、腿、围巾。黑屏是默认状态；只有已落座、对应阶段 running、任务未结束且连接正常时亮屏。坐下与起身使用插值，行走步频随时间推进。电脑图表缩略图来自现有 chart 事件。

右侧显示真实任务、角色进度、阶段预览、图表和正式报告。前往工位等视觉状态与执行状态分别标注。点击角色或角色按钮定位状态，不影响任务执行。手机端提供办公室与进度面板切换，办公室内部可横向查看全场。

## 通行规则

`web/modules/pony-model.js` 是无 DOM 的地面模型：A* 四邻接路径、膨胀后的桌椅障碍、角色脚底圆形碰撞体、独占通行队列、门开启检查及目标椅子的专用落座通道。所有路径均采样检查，不穿过桌椅或其他角色。

采用保守的单角色通行：多只小马可以同时在各自工位工作，但移动时依次通过公共通道。其余角色等待，避免相向死锁。主 Agent 和邮件角色默认坐着待命，不做持续闲逛。开启减少动态效果后缩短通行并取消步态、打字摆动，仍保留避碰。

## 事件与恢复

`web/modules/pony-office.js` 负责 SVG 渲染、真实事件适配和右侧面板。复用当前任务轮询，不新增后台执行或调用成本。`runvizReset` 建立任务范围；事件按 seq 去重，角色按 step 和职责归属。

历史任务直接恢复当前状态，不重播全部走位。快速结束且尚未进门的工作合并为已完成状态，不伪造工作。结果立即展示，不等待移动完成。终止、取消及读取断线会关闭屏幕；断线后按当前任务重试。离开分析页或隐藏标签页暂停动画，返回时重新核对任务。

## 开发与验证

修改模块后执行 `python scripts/build_console.py`，生成兼容当前服务的 `memory.js`，无需改变静态资源路径。

```powershell
node tests/test_pony_floor.cjs
node --check src/stock_predict_mailer/control/web/app.js
node --check src/stock_predict_mailer/control/web/memory.js
python scripts/build_console.py --check
```

寻路测试验证同时召唤、到达、离场、保守碰撞半径、桌椅障碍、快速完成以及减少动态效果；测试持续采样运动，避免仅检查最终位置。模型测试已加入 CI。

在 `tests/browser_console_fixture.py` 启动的独立模拟服务中，可通过 gstack `browse eval tests/browser_pony_office.js` 检查进场、亮屏、完成息屏和历史恢复。该文件使用明确标记的视觉测试事件，不能用于真实工作区。读取 `body[data-pony-check]` 获得结果。

已另外验证原有两轮 Mock 分析与会话草稿流程，白天/晚上布局、390px 页面宽度、浏览器无控制台错误。未以真实模型、真实 SMTP 或特定设备性能作为验收依据；动画目标接近 60fps，当前未作跨设备帧率保证。
