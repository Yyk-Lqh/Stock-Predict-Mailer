## 已实施

- 描摹原图的月牙头型、后缘缺口、非对称双眼与大步剪影；眼白和瞳孔按源像素拟合平滑椭圆。身体统一黑色，取消额外尖耳、嘴线、鼻孔与尾巴。
- 视频 B 的 f12–f29 共18个相位建立轮廓补间，同时改变身体、四肢、腿间空隙和围巾。实际行进距离驱动步态相位，源姿态中的起伏直接保留。
- 视频 A 前5.6秒按30fps保留原帧，六只角色共1008个头部、眼睑与围巾样本。播放时完整取同一帧姿态，再沿原帧序列返回，避免相反朝向在循环首尾被强行补间。背面没有额外眼睛。
- 蓝围巾角色空闲落座时使用两条源视频白色闭眼弧线、低垂头姿及睡眠提示；停止输入、暂停空闲游戏时钟、显示器黑屏。真实任务优先唤醒。
- 围巾使用厚度、垂端、源图提取的流苏细缝、细织纹与颗粒材质。迎面走位沿用参考三分之四侧脸，保持头型与眼睛比例。
- 隐藏的固定长度关节负责键鼠、门把手接触，画面绘制完整块状手臂。键盘适度加宽、肩部接触位置外移，椅背上沿提高。
- 门洞范围适配更宽轮廓，入场从门外 x=-52 开始；离场全身消失后在隐藏区对齐把手关门。

## 坐姿头型错乱修复（2026-11-12）

截图中的细黑条来自轮廓提取误连了睡眠角色后方的显示器：显示器灰阶约43–47，与原先低于45的黑色阈值重叠。坐姿源轮廓现在使用低于25的阈值，单独区分黑色角色和显示器。左右转头的提取范围同时扩宽，保留完整口鼻侧面。

原先每六帧采样、按轮廓顶点索引补间，会在转头时拉扯月牙角和口鼻；尤其循环首尾朝向不同时，轮廓会挤压。现在保留原始30fps的完整姿态，头部、眼睑和围巾同步取帧，沿同一路径往返闭环。
