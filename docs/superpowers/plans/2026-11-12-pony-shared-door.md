# 小马办公室门口批次通行实施计划

**Goal:** 同方向的多只小马共用一次开门和关门过程，逐只穿过门口；反方向请求等待当前批次结束，任务召回仍安全。

**Architecture:** 在纯仿真 `PonyFloor` 中用 `doorDirection`、`doorHoldUntil` 和现有 `gateOwner` 管理一段连续开门批次。首个门口请求先预留通行方向，反方向队列等待整批完成；门保持开启时，同方向队列逐只接续通过。`gateOwner` 每次只授权一只角色走近并占用门槛，避免候门角色挤在一起。最后一只通过且没有同向请求后关门，再开启反方向批次。门口状态不发起 Agent 或模型调用。

**Files:** `pony-model.js`、`tests/test_pony_floor.cjs`、必要的生命周期回归、生成的 `memory.js`、门口验收记录。

## Acceptance

- 三名同向角色经同一完整开门周期依次通过，没有关闭门时穿越或身体重叠。
- 当前批次的每只角色通过门口后才轮到下一只；同方向批次最后一只离开门扇范围后门关闭。
- 反方向的门请求等到当前门关闭后才开始开门。
- 工作任务在靠近门口、等候或穿越阶段到来时，角色不丢失、不卡门，并最终回到工位。
