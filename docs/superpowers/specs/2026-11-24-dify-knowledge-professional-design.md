# Dify 风格知识库与专业模式重构设计

日期：2026-11-24

## 目标

参考用户提供的 Dify 知识库截图，重构现有知识库模块和专业模式画布的视觉与信息架构。保留现有资料上传、队列、版本、审核、检索、索引配置、节点编辑、连线、运行、保存、恢复、导入和导出能力，不改动后端 API 契约。

## 信息架构

知识库入口使用专属工作区壳层。顶部导航保留控制台入口，进入知识库时使用浅灰背景、白色内容面板和蓝色主色。知识库主页展示创建知识库、流水线创建、外部知识库连接、标签筛选、搜索、服务 API 等入口，并以卡片展示已有知识库。

知识库详情固定左侧资料库导航，主区提供四个页面。文档页展示资料列表、上传、处理状态、版本与审核。流水线页展示处理流程入口。召回测试页保留查询、筛选、证据与规则汇总。设置页展示名称、描述、可见权限、分段模式、索引模式和检索设置，并复用现有处理与索引 API。

专业模式沿用现有工作流数据和事件逻辑，重做为 Dify 风格编辑器。顶部是编辑状态与操作工具栏，左侧为节点面板，中间为带网格的画布和连线，右侧为节点配置检查器。原有节点创建、编辑、删除、连线、撤销、保存、恢复默认、导入、导出、运行和节点状态反馈全部保留。

## 技术实现

实现范围集中在 `control/web/modules/knowledge.js`、`desktop-library.js`、`desktop-workbench.js` 和 `style.css`。复用现有 `KnowledgeUI`、`DesktopLibrary`、`DesktopWorkbench` 与请求封装。通过现有 hash 路由和数据属性事件切换子页面，不引入框架、构建链或新的静态资源依赖。外部文本继续使用 `textContent` 渲染。

知识库页面在桌面端使用专属布局类，窄屏下退回现有普通布局。专业模式在桌面端使用新的壳层和节点样式，761px 以下保持普通模式入口和可操作性。状态颜色、权限边界、CSRF、知识库作用域和异步请求竞态保护保持现状。

## 视觉基线

- 页面背景使用 `#f5f7fb`，白色面板与 `#e5e7eb` 边框。
- 主色使用 `#155eef`，主要按钮使用蓝色填充，次要按钮使用白色或浅灰。
- 顶部导航高度约 64px，知识库左侧栏约 240px，内容区最大宽度约 1440px。
- 卡片、列表、设置区统一使用 12px–16px 间距和中等圆角。状态徽标区分可用、处理中、待审阅和失败。
- 字号保持 12px–16px，标题使用高对比深色，说明文字使用灰蓝色。

## 数据与交互

知识库主页的卡片操作映射到现有创建、列表和外部连接入口。文档页继续调用现有上传、资料列表、详情、版本、审核、重试、下架和删除 API。召回测试页继续调用现有检索、规则汇总和来源定位 API。设置页继续调用现有配置、测试连接和重建索引 API。专业模式仅改变渲染壳层，节点数据和工作流 API 不变。

所有异步操作保持错误提示、禁用状态和旧请求丢弃逻辑。上传、审核、删除、下架、重建索引和保存流程仍需要现有确认步骤。页面不伪造进度、回执或服务状态。

## 验收

1. 知识库入口在桌面端呈现 Dify 风格的浅色工作区，列表、搜索、标签、创建和外部连接入口可见。
2. 文档、流水线、召回测试、设置四个页面可切换，现有 API 交互和状态语义不回退。
3. 专业模式显示顶部工具栏、左侧节点面板、网格画布、连线和右侧检查器，现有编辑与运行能力可用。
4. 761px 以下布局不溢出，输入、按钮、上传和节点编辑仍可操作。
5. 现有知识库和专业模式浏览器回归测试继续通过，静态资源检查无新增依赖。
