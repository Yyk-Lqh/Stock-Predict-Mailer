# 平台模型命令与验收

## 当前能力

阶段 A 提供固定契约、独立训练、严格向前评价、本地演示发布、按本机身份选择及只读预测。阶段 B 提供签名演示包与独立安装。阶段 C 提供快照用途授权、私有训练队列、owner 命名空间下的个人版本、共同测试集比较与显式切换。当前正式模型入口为 model-*、train-*、dataset-* 命令；原 research/demo-run 继续作为旧实验入口，其等权标签与 pickle 不导入新注册表。

当前只允许 synthetic 模型进入 demo 通道，使用时必须显式 --allow-demo。不支持 stable 发布或真实数据模型产品化。真实数据可以在显式授权及探索限制下生成候选，但不能绕过正式数据及市场规则验收。

## 固定契约

config/task-demo.json 使用 SYN000 为固定收益基准，SYN001 至 SYN005 为允许预测股票池，五个基准观测日的下一开盘到后续第六个开盘超额收益为标签。相同股票的目标不再随用户上传更多股票改变。

当前固定五个量价特征及顺序；契约含预测周期、当日截止时间、时区、价格口径和股数单位。缺少基准或有明确口径冲突时拒绝处理。基准观测日历仍需未来接入真实交易日历认证；股票缺少窗口中的某个基准日时跳过该窗口，不把缺失日自动压缩成相邻两行。

## 命令顺序

以下为合成数据演示，不需用户上传真实资料。先生成数据，从输出复制 snapshot_id：

```powershell
uv sync --extra trees
uv run stock-mailer demo-data --days 900 --stocks 16
uv run stock-mailer contract-check config/task-demo.json
uv run stock-mailer model-train <snapshot_id> --contract config/task-demo.json --cutoff 2021-06-01T20:00:00+08:00 --algorithm lightgbm --confirm-platform-data
uv run stock-mailer model-evaluate <model_version> <snapshot_id> --cutoff 2023-06-14T20:00:00+08:00
uv run stock-mailer model-publish <model_version> --evaluation <evaluation_id>
uv run stock-mailer model-select <model_version> --allow-demo
uv run stock-mailer model-predict <snapshot_id> --cutoff 2023-06-14T20:00:00+08:00 --allow-demo
uv run stock-mailer model-list
```

训练支持 ridge、lightgbm、zero、momentum。--confirm-platform-data 是可信本地发布操作对数据使用权的显式确认，不是远程认证机制，也不会自动授予平台使用上传用户数据的权利。

评价要求至少 30 个成熟特征日，且严格晚于该模型全部训练标签的结束日期；训练至少 60 个成熟特征日及三只股票。小样本拒绝评价。重复查看评价结果后继续挑模型仍可能选择过拟合，不能把此基础门禁当作完整研究审计。

## 存储和保护

workspace/registry/versions 下每个版本单独保存不可变 manifest.json、model.json 或 model.txt；演示发布新增 publication.json。Ridge 保存标准化与系数 JSON，LightGBM 保存原生文本，不从不可信 pickle 加载。SQLite 保存状态、清单及发布哈希，加载会验证文件与契约。

每个本机 principal 有独立模型选择，选择不改写模型，预测只调用 native_predict，不调用 fit 或更新选择。输出包含版本、契约、数据快照、实际行情日期、缺失证券和训练未执行标记。最新可用特征不足或行情过期会被显式呈现，不能将旧行情解释为今日预测。

当前仅为可信本机 CLI，principal 不是登录身份。未发布候选只对创建者可见；已发布平台 demo 可以被其他本机配置身份选择。没有对上传页面开放模型发布、任意模型执行或用户训练操作。真实多用户和个人训练队列待阶段 C。

当前模型预测结果为独立 JSON，尚未接到旧报告/邮件流程；该接入属于后续阶段 E，不通过伪造旧 experiment_id 复用不兼容报告。

## 阶段 B 签名包与独立安装

在已经完成阶段 A 演示发布的本地平台工作区运行：

```powershell
uv run stock-mailer model-keygen
uv run stock-mailer model-export <model_version> --output data/local/releases/platform-demo.zip
```

签名使用 Ed25519，私钥保存在 workspace/secrets/model-signing/publisher.key，公钥在相邻 publisher.pub。私钥不得分发、上传 Git、进入日志或交给客户端；Windows 还需用账户权限保护该目录，文件 mode 不等于完整 Windows ACL。命令不会覆盖已有密钥或已有输出包，避免意外替换平台信任身份。

通过可信的独立渠道将公钥及其指纹交给用户，模型包通过获准渠道分发。在演示的新工作区安装：

```powershell
uv run stock-mailer --config config/client-demo.toml model-install data/local/releases/platform-demo.zip --trust-key data/local/secrets/model-signing/publisher.pub
uv run stock-mailer --config config/client-demo.toml model-list
uv run stock-mailer --config config/client-demo.toml model-select <model_version> --allow-demo
uv run stock-mailer --config config/client-demo.toml model-predict <client_snapshot_id> --cutoff 2023-06-14T20:00:00+08:00 --allow-demo
```

上述信任路径用于同机演示；真实分发时用户取得的是单独认证过的公钥文件，不是平台私钥或无条件信任 ZIP 内附带的密钥。安装不改变当前模型选择，也不要求平台原始训练数据或重新训练。但预测仍需客户端具有至少 21 个连续基准观测日的行情窗口，真实自动行情更新尚未实现；示例历史日期不表示当前行情。

安装包只包含 release.json、signature.ed25519、一个原生模型和 model-card.md。签名覆盖模型清单、契约、训练截止、评估和文件哈希。安装先验证外部信任公钥、签名、文件白名单、大小、哈希、契约及评价时间，再登记新版本；不执行脚本、不任意解压、不加载 pickle。仅支持 synthetic 的 demo，不能通过修改渠道标记发布真实 stable。

相同版本重复安装幂等；已有版本内容冲突或文件损坏时拒绝静默修复。导入版本不能伪装成平台本地训练候选重新发布。密钥轮换、撤销列表、远程下载器和完整签名密钥托管不在这一版中，正式稳定发布需补充相应治理。

Ed25519 接口于 2026 年 10 月 25 日通过 gstack 核实官方文档：https://cryptography.io/en/latest/hazmat/primitives/asymmetric/ed25519/

## 阶段 C 私有训练队列与个人版本

### 授权记录

快照导入时自动绑定本机 owner 并写入用途记录：平台合成的演示数据保留 platform_training=true，用户导入的文件默认 platform_training=false、personal_training=true。平台训练遇到任何 platform_training=false 的记录即拒绝，不因 `--confirm-platform-data` 或 `--allow-unverified-real` 绕过。

```powershell
uv run stock-mailer dataset-auth <snapshot_id>
uv run stock-mailer dataset-authorize <snapshot_id> --revoke-platform --note "个人使用"
uv run stock-mailer dataset-authorize <snapshot_id> --platform --note "已确认平台训练权利"
```

授予平台训练必须带 --note 说明已确认的权利。授权是可撤回的本地治理记录，不是数据许可认证，也不替代真实数据合规审查。

### 队列与 worker

```powershell
uv run stock-mailer train-submit <parent_version> --snapshot <snapshot_id> --cutoff 2023-06-14T20:00:00+08:00 --timeout 600
uv run stock-mailer train-worker --once
uv run stock-mailer train-status <job_id>
uv run stock-mailer train-list
uv run stock-mailer train-cancel <job_id>
```

train-submit 继承父版本的算法、特征、标签与基准，只提交同配方完整重训练；当前仅实现 full_retrain，残差适配与方法级继续训练会被明确拒绝。提交时固化父版本、快照、契约、切分截止时间、时间与行数预算，规格哈希相同且已有排队/运行/成功任务时合并返回原任务，取消或失败后可用同一规格重新提交为新任务。

提交时即检验：快照有本机 personal_training 授权、与父契约的数据口径兼容、至少 60 个成熟特征日与 3 只证券、矩阵不超过行数预算。不足、未授权或契约不符直接拒绝，不进入队列。

worker 一次只取一个任务，在清洗过环境变量（不继承 SMTP 和 API 凭证）的独立子进程内训练，轮询进度文件并向任务记录写入阶段。子进程只写自己的暂存目录；产物由父进程校验哈希、契约、父版本与命名空间后原子落入 `workspace/registry/personal/<owner_key>/versions/<version>`，平台 `registry/versions` 目录不接受个人写入。阶段为 loading_data、preparing_features、training、evaluating、packaging、done，并保留 stages.log 轨迹。

超时按预算强制停止并标记 timeout；owner 取消标记 cancelled；子进程异常退出标记 failed 并只保留错误类别；worker 心跳过期标记 interrupted。四种情况都不产生个人版本，也不改写当前选择，已发布的旧模型继续可用。

### 共同测试集比较与切换

```powershell
uv run stock-mailer model-compare <candidate_version> --baseline <parent_version> --snapshot <snapshot_id> --cutoff 2023-06-14T20:00:00+08:00
uv run stock-mailer model-select <candidate_version> --confirm-personal
uv run stock-mailer model-predict <snapshot_id> --cutoff 2023-06-14T20:00:00+08:00 --allow-personal
```

比较要求两者契约完全一致（同特征顺序、同标签、同基准与股票池），只使用严格晚于双方训练标签结束的日期，且至少 30 个可比横截面日；不足则拒绝。指标为逐日 Rank IC 与按日区块 bootstrap 的差值区间：区间整体大于 0 记为 candidate_improved，整体小于 0 记为 candidate_degraded，跨零记为 inconclusive，不把跨零区间表述为改善。

比较只写比较记录，不切换模型，也不修改选择。个人候选必须已有比较记录且显式 `--confirm-personal` 才可被选择；预测个人版本需 `--allow-personal`，预测过程只加载原生模型，不调用 fit。演示通道仍使用 `--allow-demo`。

### 边界

单 worker、单工作区，未实现并发 worker、任务优先级或跨机器调度；本机 principal 仍是受信操作配置，不是网页登录身份，上传页面不新增训练或模型执行入口。个人训练不继承权重，不能宣称权重微调；残差适配、LightGBM 有限继续训练、漂移评价、真实行情自动更新、正式 stable 发布与生成 API/邮件闭环仍在后续阶段。

## 阶段 A 验收

测试覆盖固定基准标签不随上传股票池变化、原生 Ridge 与训练器预测一致、历史特征不受未来值改变、缺日窗口跳过、特征错序拒绝、训练及评价时点门禁、预测时禁止 fit、草稿不可选、用户选择独立、篡改拒绝、LightGBM 原生加载和发布不可改写。
