# 待认领任务

本清单把《模型能力下一步实施计划》与《实施阶段与验收》里尚未完成的工作，拆成可独立认领、可独立验收的条目。认领前请在 issue 中说明方案，并确认没有人在做同一项。

任务状态以 issue 为准；本文件只描述范围与验收口径，不代表承诺工期。所有条目都遵守 [CONTRIBUTING](../CONTRIBUTING.md) 的代码约定。

## 优先级与依赖

```text
C-1 残差适配 ── 需要时间交叉拟合，且必须先有 C-2 之外的独立评价窗口
C-2 多 worker / 优先级
C-3 产物保留策略
C-4 比较的分组与多重比较提示
D-1 LightGBM 有限继续训练 ── 依赖 D-2 的数据回放权利检查
D-2 数据回放权利与漂移评价
E-1 生成 API 接入 ── 依赖 E-2 的预测固化
E-2 预测到报告/邮件闭环
F-1 真实行情自动更新 ── 依赖 F-2 交易日历
F-2 真实交易日历与公司行动
F-3 影子运行与 stable 治理 ── 依赖 F-1、F-2、E-2
```

## 条目

| 编号 | 任务 | 难度 | 前置 | 验收要点 |
| --- | --- | --- | --- | --- |
| C-1 | 残差适配（冻结父模型 + 时间交叉拟合适配器） | 高 | 无 | 只在父模型未见样本上拟合；与同配方重训练在同一共同测试集比较；不宣称权重微调 |
| C-2 | 多 worker 与队列优先级 | 中 | 无 | 同一任务不被重复执行；优先级不影响已运行任务；单 worker 行为不回归 |
| C-3 | 训练产物保留策略 | 中 | 无 | 已选/已发布版本不被清理；清理有审计记录；不删除活动依赖的父版本 |
| C-4 | 比较的分组与多重比较提示 | 中 | 无 | 按市场阶段/流动性分段；记录比较次数与预算；样本不足时输出"证据不足" |
| D-1 | LightGBM `init_model` 有限继续训练 | 高 | D-2 | 算法能力声明 + 兼容性门禁；父子版本不可变；追加轮次有上限；与重训练同集比较 |
| D-2 | 数据回放权利检查与漂移评价 | 中 | 无 | 回放数据需显式授权；撤回后停止回放；漂移指标可复现 |
| E-1 | 生成 API 接入 | 高 | E-2 | 只接收结构化预测与最少证据；引用必须可解析；失败降级为模板；有预算与重试上限 |
| E-2 | 预测到报告/邮件闭环 | 中 | 无 | 报告固化 model_version / feature_version / snapshot；切换模型不改历史报告；无证据不得补造解释 |
| F-1 | 真实行情自动更新与新鲜度门禁 | 高 | F-2 | 过期行情显式拒绝或标注；不把旧行情解释为当日预测；更新可追溯 |
| F-2 | 真实交易日历与公司行动认证 | 高 | 无 | 用认证日历替代基准观测日历；缺日窗口跳过而不压缩；复权口径与契约一致 |
| F-3 | 十交易日影子运行与 stable 治理 | 高 | F-1、F-2、E-2 | 影子记录可审计；stable 发布有授权与撤销流程；密钥轮换与撤销列表 |
| G-1 | 跨平台差异用例补强 | 低 | 无 | 原子替换、时区、路径大小写在 Windows/Linux 均有覆盖 |
| G-2 | 上传中心 PDF/OCR（可选） | 中 | 无 | 仅归档不入模型；解析失败隔离；不上传原文到外部 |
| G-3 | 英文 README 与文档站（可选） | 低 | 无 | 与中文版同步，不夸大范围 |

## 不适合作为首个 PR 的条目

C-1、D-1、E-1、F-1、F-2、F-3 涉及契约、模型格式或真实数据授权，需要先在设计 issue 中达成一致。建议从 G-1、C-3、C-4 或文档类改进开始。

## 提交方式

1. 在本仓库开 `认领任务` issue，写清编号与方案；
2. fork 后从 `main` 切分支；
3. 按 CONTRIBUTING 跑完四项检查；
4. 提 PR，模板中勾选边界自查。
