# 日行情数据契约

CSV 使用 UTF-8，字段为 date、security_id、open、high、low、close、volume、available_at、source。date 为 YYYY-MM-DD；available_at 必须带时区，表示该条完整日线首次可用时间，不能填交易日零点冒充当时已知。价格为有限正数，成交量非负，OHLC 一致，同证券同日唯一。

导入器验证格式与数值，不替用户验证授权、供应商时点真实性、退市覆盖、证券状态或复权正确性。真实策略验收前必须提供公司行动和交易日历等配套信息。研究模块默认拒绝未认证真实数据；显式使用 --allow-unverified-real 可做探索训练，但输出持续标记 unverified_real，不能视为真实策略验收完成。

每个快照按规范化内容与 synthetic 标记计算 SHA-256，保留原始 CSV、Parquet 与完整性清单，完成标记最后写入。相同数据重复导入返回相同快照；修订产生新快照，历史版本不覆写。预测时先按 available_at 过滤，不能仅按 date 过滤。

```powershell
uv run stock-mailer demo-data --days 900 --stocks 16
uv run stock-mailer import-csv path/to/licensed-bars.csv
uv run stock-mailer snapshot <snapshot_id>
```

合成样本使用周一至周五模拟日期，不是交易所日历，无公司行动、停牌或退市，不可用于投资结论。
