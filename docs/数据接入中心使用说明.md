# 数据接入中心使用说明

## 打开本机上传页面

在项目根目录运行：

```powershell
uv sync --extra trees
uv run stock-mailer uploads
```

浏览器打开 http://127.0.0.1:8765 。页面可选择多个文件或拖放上传；上传后自动识别格式、分类、清洗并显示处理结果。仅绑定本机回环地址，不能直接给局域网其他电脑访问。Ctrl+C 停止服务；停止后文件和结果仍保留，重新启动可继续查看。

可用 --port 指定其他端口。无需配置云存储或数据平台账号。页面不训练模型、不调用外部大模型、不发送邮件，也不把原文传出电脑。

## 批量投放与命令行

默认投放目录为项目下 data/local/intake/incoming，实际以页面显示路径及 config 中的 workspace 为准。将完整文件复制进目录后点击“扫描目录”，或运行：

```powershell
uv run stock-mailer scan-incoming
uv run stock-mailer ingest-file "D:/your-data/bars.xlsx"
uv run stock-mailer ingest-file "D:/your-data/bars.csv" --options config/intake-example.json
```

扫描为手动或计划任务触发，不是后台实时文件监听。采集端应先写 .part 或 .tmp，完成后原子改名；扫描忽略隐藏文件、符号链接和这两类临时文件。已处理的相同内容不重复扫描；需要改变元数据时在页面重新清洗。用户文件必须进入本地数据目录，不能提交 Git。

## 格式与种类

支持 CSV/TSV 及可识别的逗号、制表符、分号或竖线分隔文本，编码可识别 UTF-8、带 BOM 的 UTF-16、GB18030。日期支持无歧义的年月日形式，不猜测日月顺序。

支持 XLSX 多工作表、JSON 对象数组及 data/rows/records/results 单包装数组、JSONL、Parquet、SQLite 多表，以及 TXT/Markdown。SQLite 只读访问归档副本；正在写入 WAL 模式的数据库必须先由采集端导出一致备份，不能仅复制主数据库文件。Excel 公式不执行，公式单元格所在记录会隔离，请先导出实际值。

单文件最多 50MB、总计 100000 行、250 列；多工作表和数据库最多 40 张表。大型数据应分批导出。XLSX 还限制解压体积与压缩比例。PDF、图片、旧 XLS 和普通压缩包保留原件并提示转换，当前不具备 OCR 和任意格式解析能力。

字段识别覆盖截图中的日期、股票代码、开盘、最高、最低、收盘、成交量，也识别常见英文别名。资料自动分为股票日行情、财务、新闻与公告、宏观、其他表格及文本。自动分类是基于字段规则的判断，不代表已验证资料真实或含义正确；可手工覆盖表格类别和字段映射。

财务、新闻、宏观先存为规范化文件，暂不直接作为现有量价模型的输入。文本先归档，知识库权限、发表与可用时间确认后再使用原有 kb-add 入库。不同业务类型不会拼成同一行情表。

## 自动清洗的边界

自动执行表头和字符串首尾空白清理、已支持日期规范化、明确的数值千分位处理、证券代码表示规范化、完全重复记录删除、异常 OHLCV 和格式值隔离。sh.603278 保留市场前缀；603278.SH 规范为 sh.603278；纯数字代码不猜市场，不补造已经丢失的前导零。

同证券同日出现不同记录时全部隔离，不静默取最后一条。单一成交价只作风险提示，不直接删除。空值不填零、不补交易日、不前后填充价格，也不凭截图或当前上传时间倒推历史可用时间。

完整问题清单含表名、逻辑记录号、字段与原因；页面最多展示 200 条。逻辑记录号包含表头但不含被忽略空白行，不一定等于文本编辑器的物理行号。原件始终保留，便于核查被隔离行。

## 待确认信息与发布

缺少来源、价格复权口径、成交量单位或历史实际可用时间时，行情标记“待确认”。可在页面填来源、价格口径和单位，或输入字段映射 JSON。处理选项对本文件中的所有表生效；不同表需要不同映射或来源时先按表导出，避免将一组元数据误用于所有资料。

可选的“缺失实际可用时间”只填充原文件缺失字段，不能覆盖已有时间。只填写确实知道整批记录可用的时刻，必须带时区。整批历史记录今天首次取得，可以如实记录今天取得的时间，但这些记录不能再作为过去已经可见的数据。程序不会默认添加当日收盘时间。

只有行情表的必需字段、元数据和数值检查通过，且无被隔离的异常行时，“发布为训练用行情快照”才可用。删除完全重复行不阻止发布，单一价格风险提示仍保留。成交量单位为手时拒绝直接发布；转换需要先确认市场和品种，不一律乘以 100。

发布快照保留上传 ID、处理版本、表名、价格口径、单位与时点来源说明；相同处理版本重复发布是幂等的。通过清洗只说明格式与显式规则通过，不等于授权、复权、历史股票池或可交易性认证。后续探索训练仍需 --allow-unverified-real。

## 存储与安全

workspace/intake/archive 按文件内容哈希保留原件，上传名称不会作为任意路径使用。workspace/intake/jobs 保留每个处理版本的 report.json、issues.json、table-N.json 和 table-N.parquet；文本资料保存 document.txt。原件、处理结果和快照均被现有 data/ 忽略规则保护，不上传 GitHub。

Parquet 用于分析查询，JSON 保留混合类型值；混合类型的非纯数值列在 Parquet 中转为文本，不把此变化冒充业务字段认证。每次重新清洗保留旧结果。处理失败会生成已隔离记录，不删除原件。

页面通过会话令牌、Host 和 Origin 检查限制跨站访问，原文以文本节点显示，不执行上传 HTML 或脚本。此服务用于可信本机操作，没有多用户认证、远程访问和共享权限管理，不应转发到公网。实际文件权限和备份由操作系统保护。
