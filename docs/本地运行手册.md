# 本地运行手册

要求 Python 3.11 或更新版本，推荐 uv。所有命令在仓库根目录执行。工作路径可以包含中文。示例配置不含凭证，不自动读取 .env。

```powershell
uv sync
uv run stock-mailer --config config/example.toml init
uv run stock-mailer --config config/example.toml status
uv run python -m unittest discover -s tests -v
```

配置中的 workspace 相对于配置文件所在目录解析。示例配置将运行数据写入 data/local，已被 Git 排除。修改运行参数请复制配置到 config/local.toml，并加入个人排除规则或使用受限配置路径；不得把凭证写入任何配置。

阶段性能力及限制以《阶段验收记录》为准。未取得真实数据与 SMTP 参数前，离线测试不代表已完成真实数据联调。

## 一键离线演示

```powershell
uv sync --extra trees
uv run stock-mailer demo-run --cutoff 2026-10-24T20:00:00+08:00 --trees
```

输出快照、实验、报告和邮件队列 ID，HTML 与邮件预览保存在 workspace 中。命令不发送邮件。截止时间是示例，合成数据也不会因为更改截止时间变成真实当前行情。

详细操作见《数据契约》《研究验证说明》《知识库与报告》《邮件与调度》。

## 多格式数据接入中心

运行 uv run stock-mailer uploads，在 http://127.0.0.1:8765 上传及查看清洗结果；或使用 scan-incoming 扫描 workspace/intake/incoming。支持的格式、元数据确认、手工映射和发布快照见《数据接入中心使用说明》。处理不会自动训练或发信。

## 平台与个人模型

模型契约检查、训练、评价、演示发布、签名包安装、快照授权、私有训练队列、共同比较与版本切换的命令顺序见《平台模型命令与验收》。个人训练在独立子进程运行，产物写入 workspace/registry/personal 下的 owner 命名空间；训练结束不自动切换模型。
