# 本地运行手册

要求 Python 3.11 或更新版本，推荐 uv。所有命令在仓库根目录执行。工作路径可以包含中文。示例配置不含凭证，不自动读取 .env。

```powershell
uv sync
uv run stock-mailer --config config/example.toml init
uv run stock-mailer --config config/example.toml status
uv run python -m unittest discover -s tests -v
```

配置中的 workspace 相对于配置文件所在目录解析。示例配置将运行数据写入 data/local，已被 Git 排除。修改运行参数请复制配置到 config/local.toml，并加入个人排除规则或使用受限配置路径；不得把凭证写入任何配置。

阶段性能力及限制以《阶段验收记录》为准。未取得真实数据与 SMTP 参数前，离线测试不代表已完成真实数据联调。
