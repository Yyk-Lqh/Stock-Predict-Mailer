# 知识库与报告

当前支持本地 UTF-8 .md 与 .txt，显式传入发表、可用时间和允许访问的 principal。800 字符窗口、100 字符重叠，保留版本、片段序号及内容哈希。SQLite FTS5 使用应用分词生成中文词项，配合本地 HashingVectorizer 字符向量与倒数排名融合。字符向量不是语义 embedding，当前也没有神经重排序或生成模型，效果需通过实际查询集验证。

权限与时点过滤先于检索打分；返回引用再次检查。更新使旧版本停用；撤权使既有报告不能再通过程序加载或发送。原文件、SQLite 与已导出的 HTML 仍需操作系统文件权限保护；principal 是受信本机命令行配置，不是可对外开放的身份认证服务，不能把当前 CLI 当作多租户安全系统。

旧版停用策略优先避免使用过期文件，不支持任意历史文档版本回放。若升级为研究历史回放，需要增加权限生效区间与版本有效区间，不应删除旧原文或复用旧 ID。

报告明确区分输入事实、模型预测、资料原文、推断与未知项。所有标题和文档正文进行 HTML 转义，无网络脚本或远程资源。文档中的指令不会执行。当前未调用大模型，不能声称已实现完整生成式 RAG；后续接入需单独验收结构化输出、引用支持关系、外发白名单与失败降级。

```powershell
uv run stock-mailer kb-add path/to/note.md --published-at 2026-10-23T18:00:00+08:00 --available-at 2026-10-23T18:10:00+08:00 --allow owner
uv run stock-mailer kb-search "策略风险" --cutoff 2026-10-24T20:00:00+08:00
uv run stock-mailer report <experiment_id> --query "策略风险"
uv run stock-mailer kb-revoke <document_id>
```

HTML 与 JSON 生成于本地 workspace/reports；不进入 Git。数据年龄按自然日显式展示，演示的历史数据不伪装成当前行情。无符合条件资料时不补造引用。
