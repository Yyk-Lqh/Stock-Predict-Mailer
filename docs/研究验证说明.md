# 研究验证说明

当前研究命令仅允许 synthetic 快照。真实数据必须先通过历史证券池、交易日历、公司行动、停牌及数据时点验收；CSV 导入成功不解除此限制。

特征为 1 日、5 日、20 日收益、20 日对数收益波动及相对成交量。每只股票至少需要 21 条历史记录，窗口内数据必须在该日北京时间 20 时前可用。演示中无停牌，因此记录序列相当于交易日；真实停牌需接入交易日历后重新定义。

标签为下一交易日开盘至第六个后续交易日开盘的五日收益，减去同一合成股票池的等权同期收益。基准不是授权指数，不包含分红公司行动，不表示真实可交易收益。

日期按 60%、20%、20% 分为训练、验证与最终保留集，边界处删除 label_end 不早于下一分区开始的样本。零预测、20 日动量和 Ridge 仅按验证期平均 Rank IC 选择；LightGBM 可选。收益预测 MAE 对动量分数只具有尺度参考意义，不能用其直接声称回归优劣。

开发集补充扩展窗口诊断，最终保留集单独评价。开发集滚动诊断与模型选择使用了共同历史，不是嵌套独立验证。测试完成后部署模型用全部成熟标签重训，与保留集评估模型分别保存，不能把部署模型回填到保留集重新宣称样本外效果。

成本诊断为非重叠 Top-K 组合的五日超额收益减去固定双边总成本，无资金、市场成交限制、成交量参与率或真实滑点建模，因此不是实盘级回测。不提供年化收益承诺或概率置信输出。未来阶段补齐完整模拟与置信区间再讨论真实策略。

实验保留代码提交、数据快照、截止时间、特征、参数、模型 SHA-256 和切分边界。pickle 仅为本地自有模型归档，禁止载入不可信模型文件。工作区未提交改动期间的实验仅供开发；发布后按提交版本重新运行。
