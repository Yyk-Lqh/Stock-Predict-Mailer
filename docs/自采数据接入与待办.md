# 自采数据接入与待办

## 已确认条件

用户已确认在自有电脑运行，电脑有 GPU，可使用外部大模型 API，数据由用户自行收集。内存容量、GPU 型号和显存尚未提供；市场、股票池与数据细节尚未确认。不替用户采购数据，不默认任何已有数据许可。

当前优先提供自采 CSV 本地训练流程。GPU 不作为表格模型的必要条件，默认 CPU 路线；硬件信息确定后再评估加速。外部生成 API 的供应商、模型、接口地址和资料外发等级尚未指定，因此本次不接入或调用任何生成服务，也不发送私有原文。

## 文件准备

建议把用户自采文件存入 data/incoming，此目录不会上传 GitHub。至少提供《数据契约》要求的九个字段。一个日期多只股票可放在同一 CSV；同一证券同日只保留一个明确版本。当前导入按完整输入形成快照，不自动合并多批次 CSV；增量采集端需先去重和版本化，不能直接拼接重复记录。

训练至少需要 100 个有标签日期及特征预热和预测期，实际建议更长历史与足够横截面。默认五日标签和 21 条日线预热意味着一般需 130 个以上完整观测日期。股票数过少或同日有效证券少于三只时 Rank IC 不适用；没有足够样本时应停止实验。

available_at 必须是该条完整记录真正可用的带时区时间，不能只填财报报告期或新闻日期。若无法取得可靠时间，记录为研究限制，不虚构时点。原始价格与复权口径需另行说明；公司行动缺失会影响收益与特征。

## 本机操作

```powershell
uv sync --extra trees
uv run stock-mailer import-csv data/incoming/bars.csv
# 使用上一步输出的 snapshot_id，显式接受未认证数据限制
uv run stock-mailer research <snapshot_id> --cutoff 2026-10-24T20:00:00+08:00 --trees --allow-unverified-real
uv run stock-mailer report <experiment_id> --query "风险 策略"
```

不要把真实数据加 --synthetic 伪装成演示。探索入口只提供数据处理和模型验证框架，不提供经过认证的可交易回测。真实数据中的缺失市场日期、停牌、退市和公司行动需独立处理，当前按观测日期定义的标签可能偏离五个真实交易日。
