# 邮件与调度

## 默认仅预览

```powershell
uv run stock-mailer demo-run --cutoff 2026-10-24T20:00:00+08:00
uv run stock-mailer outbox
```

一条命令完成合成数据、研究、模板报告及 .eml 预览。不会读取 SMTP 凭证或发送邮件。相同代码、快照、截止时间和证据重复运行不会重复创建邮件。不同截止时间、代码或证据形成新版本；当前演示每次重训，不作为真实生产每日推理调度。

## 显式发送

首先使用 queue-mail 明确真实收件人与发件人，再调用 send-mail。SMTP_HOST、SMTP_USER、SMTP_PASSWORD 从本机环境读取；SMTP_MODE 为 starttls 或 ssl，SMTP_PORT 可选。凭证不要写入 PowerShell 命令历史或版本库，建议通过凭据管理器和受限进程环境注入。当前不自动读取凭据管理器。

```powershell
uv run stock-mailer queue-mail <report_id> --recipient your-address@example.com --sender your-address@example.com
uv run stock-mailer send-mail <outbox_id>
```

合成或过时报告默认拒绝发送，测试若确需发送，显式添加 --allow-synthetic 或 --allow-stale。调度与演示命令不添加这些标志。报告资料撤权或内容哈希不符时不能发送。

Outbox 状态包括 pending、retry、sending、submitted、failed、uncertain。提交前连接失败可有限重试，默认最多三次，间隔按五分钟乘尝试次数增长；调度调用者负责到期后显式调用。开始 SMTP 数据发送后连接超时标记 uncertain，不自动重发。异常进程留下的 sending 在下一次发送时转为 uncertain，需人工核对服务端记录。submitted 仅表示服务器接受，不代表最终送达。

## Windows 调度

scripts/run-demo.ps1 使用绝对解释器和工作目录，scripts/register-task.ps1 是可选注册工具，默认每天 20 时运行合成预览，错过后尽快运行、不覆盖同名任务、不存密码。该任务尚未在用户电脑注册；运行前需确认时间和登录策略。PowerShell 执行策略如阻断，应采用组织允许的脚本签名或策略，不在脚本中绕过。

```powershell
./scripts/run-demo.ps1
./scripts/register-task.ps1 -At "20:00"
```

互斥锁由操作系统管理，进程退出后自动释放，不依赖删除过期锁文件。启动后把被中断的同类演示任务标记 interrupted；内容寻址快照和实验允许从头重跑。真实生产还需要按供应数据水位补采和已审核模型推理，这部分在用户数据接入阶段完成，不将演示补跑等同于完整生产恢复。

## 备份与运维

退出写入进程后备份整个 workspace，或使用 SQLite backup API 并同时冻结文件快照。备份到另一块物理磁盘或自有 NAS，不向公共仓库上传。至少定期验证数据库能打开、快照哈希一致与报告能加载；恢复后处理凭证、撤权和 uncertain 邮件状态。电脑关机期间不保证告警和准时推送。
