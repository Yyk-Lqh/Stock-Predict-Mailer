本机分析工具

把上游的预测，变成一份能核对、能发出的报告。

数据与模型团队把预测结果和客观事实交给这里，它逐项校验后写出分层报告：哪些是上游给的事实、哪些是 Agent 的推断、哪里缺信息、哪里有风险。 报告可以按你预先授权的地址发出去。它不训练模型、不采集行情，也不保证收益。

    它做什么

    • 先校验再分析。对象、周期、有效期、事实来源不合规，直接拒绝，不会拿错数据编一份报告出来。
    • 分层写清楚。事实带来源与观测时间，推断标注引用了哪几条事实，限制和风险单独成段。
    • 投递留痕。谁授权、发到哪、结果是模拟还是已提交，都记在报告里。

    它不做什么

    • 不训练、不加载上游模型权重。预测值来自上游，这里只做解读。
    • 不采集行情、不承诺收益。没有 K 线，也没有买卖点。
    • 不替你扩大权限。没授权的收件人一律拒绝，状态不确定的邮件也不会自动重发。
